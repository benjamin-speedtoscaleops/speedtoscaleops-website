# Speed To Scale Ops — website

Marketing site for **Speed To Scale Ops** (speedto-scale-ops.com): a static, no-build site — plain HTML + CSS.

- `index.html` — the whole site (single page)
- `css/style.css` — styles
- `favicon.svg` — lightning-bolt favicon

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
```

## Deploying

Built to work on GitHub Pages as-is. For the custom domain, add a `CNAME` file containing `speedto-scale-ops.com` and point the domain's DNS (Namecheap) at GitHub Pages.
